Подборка от 29.10.2026. Поиск выполнен через Inspo MCP с mode=dark; ответы — inspo-dark-0.json, inspo-dark-1.json, inspo-dark-2.json. Дополнительно найден прямой мясной e-commerce концепт на Dribbble.

https://dribbble.com/shots/27627760-Meat-Shop-Website-Design
Концепт премиального мясного магазина: тёмные красно-коричневые оттенки, выразительная типографика, фотографии мяса. Основной кандидат для мясной витрины Beef Derbent.

https://onyxcoffeelab.com/

3. Atomix
https://www.atomixnyc.com/
Inspo: atomixnyc-com. Ресторанный референс только для визуального направления: фактуры, тёмные землистые оттенки, сдержанные акценты. Для Beef Derbent нужен явный вход в каталог.

4. Dinner by Heston
https://www.dinnerbyheston.com/
Inspo: dinnerbyheston-com. Ресторанный типографический референс: угольно-серый, светлая антиква, тонкие линии, много пространства. Адаптировать к карточкам товаров и видимым элементам покупки.

Рекомендация: композиция и продуктовая фотография Nixtio, редакционная подача Onyx, типографическая сдержанность Dinner.
