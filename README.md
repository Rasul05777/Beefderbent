# Beefderbent — реализация по референсу

Локальный запуск: `python3 -m http.server 4173 --bind 127.0.0.1`

Главная: http://127.0.0.1:4173/
Каталог: http://127.0.0.1:4173/catalog.html
Категория: http://127.0.0.1:4173/catalog.html?category=miaso-i-ptitsa
Карточка товара: product.html?product=<slug>

## Наполнение

Категории и будущие товары находятся в `catalog-data.js`. Массив `products` оставлен пустым по запросу пользователя. Для добавления товара:

```js
{slug:'unique-product-slug',category:'miaso-i-ptitsa',name:'Название',description:'Описание',image:'assets/products/photo.jpg',price:850,unit:'кг'}
```

После добавления данных товар автоматически появится в своей категории со ссылкой на отдельную карточку. Для неизвестной категории или товара предусмотрено понятное сообщение с возвратом в каталог. Товары, цены, оплата и оформление заказа пока не подключены.

Поиск работает по категориям. Способ покупки (в заведении / самовывоз) хранится на устройстве; это предпочтение, а не отправка заказа. Контакты соответствуют предоставленному референсу и исходному магазину. Карта — Яндекс Карты. Фотографии категорий — иллюстрации Unsplash; главный фон создан Imagegen. Для длинного списка категорий некоторые фото используются повторно; их можно заменить реальными изображениями при наполнении.

## Сохранённые варианты

- `/dark-v2/` — предыдущий тёмный сайт.
- `/atelier/` — типографический вариант с оранжевой панелью.
- `/light/` — первый светлый вариант.

## Проверка

Проверены синтаксис JS, ссылки на локальные изображения, поиск и переход в категорию, пустое состояние, диалоги. Главная и категория проверены в браузере на ширинах 1536 и 390 px без горизонтального переполнения. Товары намеренно отсутствуют; шаблон карточки подготовлен для последующего наполнения.

## Размещение на сервере

Сайт статический: установка Node.js, npm и сборка не требуются.

1. Скачайте репозиторий: **Code → Download ZIP** или `git clone https://github.com/Rasul05777/Beefderbent.git`.
2. Загрузите в корень сайта файлы `index.html`, `catalog.html`, `product.html`, `style.css`, `theme-red.css`, `app.js`, `catalog-data.js` и папку `assets/`, сохраняя структуру.
3. Если нужны предыдущие дизайны, загрузите также `light/`, `dark-v2/` и `atelier/`.
4. Откройте домен по HTTP/HTTPS. Стартовая страница — `index.html`. Перенаправление всех адресов на `index.html` не требуется: каталог и карточка товара являются отдельными HTML-страницами.

Сервер должен отдавать `.js` как JavaScript (`text/javascript` или `application/javascript`), поскольку сайт использует ES-модули. Локально открывайте сайт через HTTP-сервер, а не двойным щелчком по HTML-файлу.

Шрифты загружаются с Google Fonts, интерактивная карта — с Яндекс Карт. При недоступности внешних сервисов остаются системные шрифты и ссылка на карту. Фото сайта хранятся в `assets/`.

Сайт не содержит базы данных, авторизации или приёма оплаты. Наполнение товаров предусмотрено в `catalog-data.js`.

## Чёрно-красный интерфейс

Текущая версия оформлена по референсу от 19.11.2026: SVG-знак быка, красные акценты, заголовки без засечек, иконки категорий. Дополнительный файл `theme-red.css` необходимо загрузить на сервер вместе со `style.css`.

Кнопка «В заказе 0» открывает пустое состояние заказа. Товары, оплата и отправка заказа пока не подключены. Выбор способа покупки доступен в этом окне. Предыдущая золотистая версия сохранена в `/gold-v1/`.


## Уточнение референса — 21.11.2026

Для категорий «Мясо и птица», «Замороженные продукты», «Сыры», «Сахар, соль, специи» и «Рыба и морепродукты» созданы отдельные иллюстративные изображения в едином тёмном стиле. Файлы находятся в `assets/categories/`; это изображения категорий, не фотографии фактических товаров магазина. Высота первого экрана уточнена для более близкой композиции к референсу.

## Утверждённый макет — 22.11.2026

Логотип, фото первого экрана и фото десяти основных категорий теперь используют фрагменты предоставленного макета `assets/reference/approved-design.png` через CSS-фоны. Это один общий графический ресурс, а не изображение вместо страницы. Заголовки, подписи категорий, иконки, кнопки, диалоги и переходы остаются HTML/SVG. Для основных категорий координаты фрагментов находятся в `referencePhotos` внутри `app.js`; остальные категории и внутренние обложки используют отдельные изображения из `catalog-data.js`. При добавлении реальных фотографий замените `photoFragment` на обычный вывод `c.image`.

На ширине 1600 px шапка занимает 88 px, блок категорий начинается на отметке 471 px, как на приложенном макете. Адаптивная версия сохраняет две колонки категорий на телефоне.


Кнопка «Как нас найти» и ссылка под встроенной картой открывают Яндекс Карты с отметкой магазина в новой вкладке.
